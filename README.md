## 🧭 Project Overview

주정차 차량, 트럭, 담장 등에 가려진 보행자는 운전자 시점에서 늦게 보일 수 있습니다. **BlindGuard AI**는 도로변 카메라로 보행자를 탐지·추적하고, 차로 진입 가능성과 차량의 접근 상황을 함께 살펴 운전자에게 필요한 위험 정보만 전달하는 프로젝트입니다.

현재 목표는 **보행자 탐지 → 동작·차로 진입 판단 → 경고 전달**까지 이어지는 파이프라인을 구현하고, 시뮬레이션과 측정 데이터를 통해 적시성과 오경고를 평가하는 것입니다.

> **Research question**  
> 차량에서 가려진 보행자의 차로 진입을 도로변 영상에서 얼마나 일찍 판단하고, 운전자에게 필요한 경고만 제때 전달할 수 있을까?

## ✨ Core Ideas

| 영역 | 접근 방식 |
|---|---|
| 사각지대 관찰 | 도로변 카메라로 인도와 차로 진입 경계를 관찰 |
| Vision 연구 | 보행자 탐지·추적 결과에서 이동 방향과 차로 진입 의도를 분석 |
| 선택적 경고 | 보행자 진입 예상 시간과 차량 접근 시간을 비교하고 현장 가시거리를 고려 |
| 시스템 검증 | 시뮬레이션 및 실제 영상에서 적시 경고, 불필요 경고, 전체 지연을 측정 |

차량에 가려진 보행자를 인프라에서 관찰하는 것과 보행자 횡단 의도 예측 자체는 이미 연구된 주제입니다. 이 프로젝트는 **도로변 카메라의 관찰 결과를 운전자별 경고로 연결하는 전체 흐름과 그 실효성**을 검증하는 데 집중합니다.

## 🧩 System Pipeline

```mermaid
flowchart LR
    A["도로변 카메라"] --> B["보행자 탐지·추적"]
    B --> C["동작·차로 진입 예측"]
    C --> D["경고 이벤트"]
    D --> E["차량 위치·접근 판단"]
    E --> F["운전자 알림"]
```

- **Edge / Vision:** 보행자를 추적하고 차로 진입 시점의 후보 구간을 추정합니다.
- **Server / App:** 차량의 위치와 이동 상태를 반영해 경고 대상을 선택하고 알림을 전달합니다.
- **Simulation:** 가림, 보행자 움직임, 차량 접근을 재현해 경고 로직을 점검합니다.

> 이 구조는 개발 목표입니다. 실제 장비의 처리 속도와 경고 지연은 통합 실험으로 확인할 예정입니다.

## 📊 Evaluation Plan

| 지표 | 확인할 질문 |
|---|---|
| 적시 경고율 | 운전자가 대응 가능한 시점에 경고가 도착했는가? |
| 불필요 경고율 | 차로에 진입하지 않거나 관련 없는 차량에 경고하지 않았는가? |
| 탐지·추적 성능 | 먼 거리, 작은 보행자, 가림 상황에서 놓치지 않는가? |
| End-to-end 지연 | 촬영부터 앱 알림까지 실제로 얼마나 걸리는가? |

기본 비교는 **일괄 경고 → 진입 시간 고려 → 차량 접근·가시거리 고려** 순서로 수행할 계획입니다. 성능 수치는 실험 후 공개합니다.

## 📌 Current Scope

첫 단계에서는 **보행자**와 **차로 진입 전 경고**에 집중합니다. 자전거·킥보드, 여러 카메라 연계, 정교한 관리자 화면은 후속 확장 대상으로 둡니다. 현재 문서의 예측 시간과 지연 수치는 목표·가정이며, 검증된 성능으로 해석하지 않습니다.
